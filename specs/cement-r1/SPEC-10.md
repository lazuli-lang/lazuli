## Justification (token / entropy)
"LLM-first expected-tokens-to-correct-output = tokens-per-attempt × attempts. SPEC-10 attacks the ATTEMPTS multiplier hardest. (1) PEAKEDNESS / output entropy: today an LLM grepping examples/ for 'how do I write this' hits twelve flat files, nine of which announce they 'may lag' codegen (examples/audit-log.lzi:3 etc.) and several of which model the SAME capability the curated/full-capsule set models differently (flat inline `surface` vs sibling `.lzx`). Multiple non-authoritative exemplars per intent is exactly the high-entropy condition that inflates retries — the model samples a stale shape, doctor rejects, it resamples. Collapsing to ONE certified exemplar per pattern (curated/) + ONE kitchen-sink (full-capsule) sharpens the distribution toward the single doctor-clean form, cutting attempts. (2) The per-commit examples_are_doctor_clean gate makes the reference library provably correct, so an LLM can copy a curated example with ZERO verification round-trips — the highest-leverage attempts reduction, since a wrong exemplar costs a full generate→doctor→fix cycle (~thousands of tokens) every time. (3) tokens-per-attempt: the curated examples are authored in the FINAL surface, which other SPECs optimize toward tokenizer-cheap English-keyword + bare-PascalCase forms; SPEC-10 does not regress this (zero registry edits, keyword-reference unregenerated) and ensures the reference corpus the model reads is the cheap surface, not a legacy @sigil-heavy one. (4) The LZI-EXAMPLE-NO-DISCLAIMER rule structurally forbids re-introducing a hedged/uncertified exemplar — keeping the corpus peaked over time, not just at one commit. Net: fewer attempts (peaked, verified corpus) at equal-or-lower tokens-per-attempt (final cheap surface), strictly lowering expected tokens-to-correct-output."
