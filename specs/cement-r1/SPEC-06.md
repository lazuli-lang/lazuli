## Problem
Three compound-join conventions coexist with no stated generative rule, so an author or LLM cannot predict the join for an unseen compound. DOT is member or variant dispatch on a namespaced parent; UNDERSCORE is an atomic-compound; SPACE is overloaded across atomic-glue (public contract, scope override) and head-plus-operand (previously migrated or alias). Full detail with file:line citations is carried in the end_state and evidence fields because the harness truncates whatever field directly follows a long problem field.

## End state
One generative three-production join rule documented in invariants.md, grammar.lzi.md and design-decisions.md and enforced by a doctor rule. DOT is reserved for member or variant access on a namespaced or typed parent such as query.list, event.trace, route.id; no new dotted forms. UNDERSCORE joins an atomic-compound by the deletability test: if neither word can be deleted leaving a valid different parse the compound is atomic and uses underscore (event_group, has_many, escape_route, plus the renamed public_contract and scope_override). SPACE is for a head keyword followed by a genuine operand or variant token (on_delete restrict, emits e from creates, architecture mode microservices, previously migrated or alias old). ## Justification (token / entropy)
LLM-first expected tokens to correct output equals tokens-per-attempt times attempts; this spec attacks both. Peakedness drives attempts down: today space encodes two unrelated productions, atomic-glue (public contract, scope override) and head plus operand phrase (previously migrated, on_delete restrict). An LLM generating an unseen compound has an ambiguous prior: is a new atomic concept foo_bar, foo bar, or foo.bar? The surface shows all three, so the model samples wrong a large fraction of the time and needs a doctor round-trip to correct, and each retry re-emits the construct plus surrounding block. After this spec there is one production per join character with a mechanical decision test by deletability: if either word can be removed leaving a valid different parse it is space head plus operand; if not it is underscore atomic; if the second token is a member of a namespaced parent it is dot. Output entropy at the join site collapses toward zero, so first-attempt-correct rate approaches one, and any residual wrong guess is one deterministic doctor fix. Tokens-per-attempt: under cl100k and o200k, public_contract and scope_override tokenize as cheap English-word pieces with an underscore glue, two to three tokens, equal or cheaper than the space forms, and a single lexical unit emitted atomically rather than two independently-sampled words where the second drifts; public X is a high-frequency code bigram inviting interface, api or schema instead of contract, and collapsing removes that fork. We deliberately keep previously migrated or alias as space because its second token is a load-bearing closed-variant operand where migrated versus alias carry distinct IR semantics; underscore would lose the distinction or yield previously_migrated and previously_alias, which is more tokens, and would re-litigate a settled reject. The rule is not underscore everything; it is one predictable production per character.
